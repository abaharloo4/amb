# AMB Personal Platform — پلتفرم شخصی و تخصصی امیرمحمد بحرلو

پلتفرم مدرن، سریع و دو زبانه نمونه‌کارها و خدمات مهندسی نرم‌افزار امیرمحمد بحرلو (`abaharlou.ir`).
طراحی‌شده با معماری SSR تمیز در لاراول ۱۱، همراه با صحنه تعاملی ۳ بعدی Three.js، سیستم مدیریت محتوای اختصاصی، محاسبه‌گر هزینه پروژه و ماژول رزرو جلسه.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

- **استک نرم‌افزاری مدرن**: Laravel 11 + Blade (SSR) + Tailwind CSS + Alpine.js + Three.js + GSAP.
- **گرافیک تعاملی سه‌بعدی (Three.js Hybrid Scene)**:
  - ترکیب مدارهای چرخان هماهنگ و شبکه سیگنالینگ موجی در هدر لندینگ.
  - مدیریت مصرف منابع و مانیتورینگ نرخ فریم (FPS Counter).
  - سازگاری خودکار با کاهش نرخ انیمیشن سیستم (`prefers-reduced-motion`) و تطبیق رنگ‌ها با تم سایت.
- **دو زبانه کامل (Bilingual FA / EN)**:
  - پشتیبانی کامل از RTL (فارسی به عنوان زبان پیش‌فرض) و LTR (انگلیسی).
  - سوئیچر زبان روان همراه با تفکیک مسیرها (`/fa` و `/en`).
- **دیزاین‌سیستم و تم پایدار (Zero-Flash Dark/Light Mode)**:
  - بیش از ۸۵ آیکون برداری SVG یکپارچه بدون ایموجی (`<x-ui.icon>`).
  - پالت رنگی حرفه‌ای (Dark Gray / Indigo / Electric Cyan) با کنتراست استاندارد WCAG.
  - کاتالوگ کامپوننت‌های رابط کاربری در آدرس `/_ui`.
- **موتور پنل ادمین سفارشی (Custom Lightweight CRUD Engine)**:
  - بدون وابستگی به پکیج‌های سنگین؛ فرم‌ساز و جدول‌ساز اختصاصی با پشتیبانی از چندزبانی و ویرایشگر Markdown.
  - احراز هویت امن و کنترل دسترسی بر پایه نقش‌ها (Spatie RBAC).
- **لید جنریشن و تعاملات هوشمند**:
  - **محاسبه‌گر هوشمند هزینه پروژه** (`/fa/estimator`) با تخمین آنی بر حسب تومان.
  - **سیستم رزرو آنلاین جلسات مشاوره** (`/fa/booking`) با قفل همزمانی دیتابیس (`lockForUpdate`) جهت ممانعت از تداخل زمان‌ها.
  - فرم استعلام و ارسال درخواست همکاری (`/fa/contact`) همراه با ذخیره امن در پایگاه داده.
- **بهینه‌سازی و سئو پیشرفته (SEO & Schema.org)**:
  - ساختار داده‌های استاندار JSON-LD (`Person`, `WebSite`, `CreativeWork`, `BlogPosting`).
  - متاتگ‌های داینامیک، OpenGraph و توییتر کارت.
- **آماده استقرار روی هاست‌های اشتراکی بدون SSH (ParsPack cPanel Ready)**:
  - اسکریپت بیلد خودکار `npm run release` جهت تولید فایل فشرده آماده استقرار (`release.zip`).
  - فایل نصب و به‌روزرسانی تحت وب (`/_install` و `/_update`).
  - کانفیگ استاندارد `.htaccess` روت برای مسیریابی مستقیم به دایرکتوری `public`.

## 🛠 راه‌اندازی و اجرای محلی (Local Development)

### پیش‌نیازها
- PHP >= 8.2 (همراه با اکستنشن‌های pdo_mysql, mbstring, curl, gd)
- MySQL / MariaDB (مثلاً WAMP Server روی پورت 3306)
- Composer
- Node.js >= 18 و npm

### مراحل راه‌اندازی گام به گام

1. **کلون کردن مخزن و نصب وابستگی‌ها:**
   ```bash
   git clone https://github.com/abaharloo4/amb.git
   cd amb
   composer install
   npm install
   ```

2. **تنظیم فایل محیطی (`.env`):**
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
   تنظیمات دیتابیس WAMP خود را بررسی و ذخیره کنید:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=amb_db
   DB_USERNAME=root
   DB_PASSWORD=
   ```

3. **مهاجرت و سید جداول دیتابیس:**
   ```bash
   php artisan migrate --seed
   ```
   > **اطلاعات حساب پیش‌فرض ادمین:**
   > - ایمیل: `admin@abaharlou.ir`
   > - رمز عبور: `Password123!`

4. **کامپایل فایل‌های فرانت‌اند:**
   ```bash
   npm run build
   # یا برای توسعه مداوم:
   npm run dev
   ```

5. **اجرای سرور محلی:**
   ```bash
   php artisan serve --port=8000
   ```
   اکنون پلتفرم از طریق آدرس `http://127.0.0.1:8000` در دسترس است.

## 📦 نحوه استقرار روی هاست پارس‌پک (cPanel Deployment Guide)

از آنجا که هاست‌های اشتراکی cPanel فاقد دسترسی SSH و Node.js هستند، مراحل استقرار به سادگی زیر طراحی شده است:

1. **تولید بسته مستقل انتشار:**
   در سیستم خود دستور زیر را اجرا کنید:
   ```bash
   npm run release
   ```
   این دستور تمام فایل‌های استایل و اسکریپت را کامپایل کرده و فایل `release.zip` را تولید می‌کند.

2. **آپلود در cPanel:**
   - وارد File Manager در cPanel شوید.
   - فایل `release.zip` را در پوشه `public_html` آپلود کنید.
   - فایل را Extract نمایید.

3. **تنظیم پایگاه داده در cPanel:**
   - یک دیتابیس MySQL و نام کاربری بسازید و دسترسی کامل دهید.
   - فایل `.env` را در روت باز کرده و مشخصات دیتابیس هاست را وارد کنید.
   - مقدار `APP_ENV=production` و `APP_DEBUG=false` را تنظیم نمایید.

4. **اجرای نصب‌کننده تحت وب:**
   - در مرورگر به آدرس زیر بروید:
     ```
     https://yourdomain.com/_install?token=YOUR_APP_KEY
     ```
   - این دستور به صورت خودکار جداول دیتابیس را مایگریت کرده و کاربر ادمین را ایجاد می‌کند.

## 📂 ساختار مهم پروژه (Architecture Overview)

```
├── app/
│   ├── Http/Controllers/       # کنترلرهای وب، پنل ادمین، لید جنریشن
│   ├── Models/                 # مدل‌های دیتابیس همراه با ترِیت‌های ترجمه
│   └── Support/                # هلپرهای سئو، تاریخ جلالی، نرمال‌سازی متن
├── database/
│   ├── migrations/             # ۲۴ مایگریشن دو زبانه ساختار دیتابیس
│   └── seeders/                # سیدرهای داده‌های نمونه، دسترسی‌ها و ادمین
├── resources/
│   ├── css/                    # استایل‌های Tailwind و توکن‌های دیزاین
│   ├── js/
│   │   ├── three/              # موتور و سناریوهای ۳ بعدی (HeroLab, HeroHybridScene)
│   │   ├── motion/             # ستاپ GSAP و افکت‌های پارالاکس و اینترکشن
│   │   └── app.js              # ستاپ Alpine.js و ماژول‌های تم
│   └── views/
│       ├── admin/              # نماهای پنل مدیریت اختصاصی و فرم‌های داینامیک
│       ├── components/ui/       # کامپوننت‌های دکمه، اینپوت، کارت، مودال و اسپرایت آیکون
│       ├── pages/              # صفحات لندینگ، پرتفولیو، وبلاگ، خدمات، رزومه و تماس
│       └── layouts/            # قالب اصلی دو زبانه
├── routes/
│   └── web.php                 # روت‌های دو زبانه عمومی، پنل ادمین و اینستالر
└── scripts/
    ├── build-release.js        # سازنده آرشیو مستقل release.zip
    └── generate-icons.js       # کامپایلر اسپرایت آیکون‌های SVG
```
