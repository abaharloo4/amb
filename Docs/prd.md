# PRD — AMB Personal Portfolio

وضعیت: پیش‌نویس Phase 0 | نسخه: 0.1 | منبع: AMB_Master_Prompt.md + AMB_Phase_Prompt_v2.md

## 1. خلاصه محصول

AMB یک پلتفرم برند شخصی برای AmirMohammad Baharlou روی دامنه abaharlou.ir است. هدف آن فقط نمایش رزومه نیست؛ سایت باید سه کار را هم‌زمان انجام دهد:

1. **اعتبار:** نمایش تخصص، نمونه‌کار و محتوا با هویت بصری اختصاصی (Three.js و GSAP به‌عنوان امضای برند).
2. **جذب مشتری:** مسیر روشن از بازدید تا درخواست همکاری، تخمین هزینه و رزرو جلسه.
3. **مدیریت:** پنل اختصاصی برای مدیریت کامل محتوا، درخواست‌ها و تنظیمات بدون ویرایش کد یا دیتابیس.

## 2. اهداف و معیارهای موفقیت

| هدف | معیار قابل‌سنجش |

## 3. مخاطبان

- **کارفرما/مشتری بالقوه:** می‌خواهد سریع تخصص، نمونه‌کار مرتبط و راه تماس را ببیند.
- **همکار یا استخدام‌کننده:** رزومه، مهارت‌ها و سوابق قابل تأیید را می‌خواهد.
- **خواننده محتوا:** مقاله‌های فنی را از موتور جست‌وجو پیدا می‌کند.
- **مدیر سایت (AMB):** محتوا، درخواست‌ها و جلسه‌ها را مدیریت می‌کند.
- **مشتری ثبت‌نام‌شده (آینده):** زیرساخت آماده است، فعال‌سازی در فاز آینده.

## 6. نیازمندی‌های کارکردی کلیدی

### 6.1 سایت عمومی
- مسیرهای مستقل `/fa` و `/en` با slug و متادیتای مستقل.
- ساختار صفحه اصلی قابل چینش از پنل: Hero، معرفی، خدمات، نمونه‌کار، آمار واقعی، روند کار، مهارت‌ها، GitHub، نظرات، مقاله‌ها، CTA، Footer.
- صفحه هر خدمت: معرفی، مسئله، راه‌حل، روند، خروجی‌ها، FAQ، نمونه‌کار مرتبط، CTA.
- صفحه هر پروژه: خلاصه، مسئله، نقش، فناوری، فرایند، چالش، نتیجه (فقط داده واقعی)، گالری، لینک‌ها، پروژه‌های مرتبط.
- وبلاگ: دسته، برچسب، جست‌وجو، فهرست مطالب، زمان مطالعه، مقالات مرتبط.
- تم روشن/تاریک بدون Flash، ذخیره ترجیح، هماهنگی کامل با Canvas.

### 6.2 جذب مشتری
- فرم درخواست همکاری 5 مرحله‌ای با اعتبارسنجی هر مرحله، حفظ داده، بازبینی نهایی، ضد ثبت تکراری، ضد اسپم، کد پیگیری و اعلان به مدیر.
- تخمین هزینه از قواعد پنل، با برچسب «تخمین اولیه»، قابل تبدیل به درخواست همکاری.
- رزرو جلسه با نمایش زمان‌های آزاد، قفل هم‌زمانی، لغو/تغییر و مدیریت وضعیت.

### 6.3 پنل مدیریت
- داشبورد، مدیریت همه محتوا و ماژول‌ها، رسانه، کاربران/نقش‌ها، تنظیمات، SEO/ترجمه.
- Draft/Publish، پیش‌نمایش، فیلتر، جست‌وجو، Pagination، تأیید عملیات حساس، Audit.
- ساخته‌شده روی هسته CRUD مشترک و کتابخانه کامپوننت سایت.

### 6.4 سیستم طراحی
- Component-First، پالت رسمی AMB با Design Tokens، بدون ایموجی، فقط SVG (جزئیات در `design.md`, `components.md`, `icons.md`).

### 6.5 Three.js و GSAP
- Hero سه‌بعدی اختصاصی، presetهای مرکزی انیمیشن، Fallback، Quality Tiers (جزئیات در `motion.md`).

## 7. نیازمندی‌های غیرکارکردی

- **عملکرد:** صفحات Server-rendered؛ Three.js فقط با بارگذاری تنبل و فقط در صفحات دارای صحنه.
- **امنیت:** طبق `security.md`؛ کنترل دسترسی سمت سرور، CSRF، Rate Limit، اعتبارسنجی آپلود.
- **دسترسی‌پذیری:** کیبورد، فوکوس، صفحه‌خوان، کنتراست در هر دو تم، reduced-motion.
- **سازگاری:** مرورگرهای مدرن؛ موبایل، تبلت، لپ‌تاپ، نمایشگر بزرگ.
- **توسعه‌پذیری:** Modular Monolith؛ افزودن مرحله فرم یا ماژول جدید بدون بازنویسی.
- **استقرار:** cPanel پارس‌پک، بدون SSH و Node، با بسته Release و Installer/Updater وب.

## 8. قیود

- هاست: آخرین PHP، بدون SSH، بدون Node، Cron موجود؛ مشخصات دقیق باید با اسکریپت تشخیص محیط ثبت شود.
- Queue فقط با driver دیتابیس و Cron.
- لوگوی نهایی وجود ندارد؛ لوگوتایپ موقت.
- محتوای واقعی آماده نیست؛ Demo با برچسب مشخص.
- GitHub و سرویس‌های خارجی ممکن است از هاست ایرانی پایدار نباشند؛ کش با Cron.

## 9. فرضیات

- پارس‌پک Cron را با دسترسی کافی (حداقل هر دقیقه) ارائه می‌دهد.
- افزونه‌های لازم PHP (`mbstring`, `intl`, `gd` یا `imagick`, `pdo_mysql`, `fileinfo`, `zip` و غیره) فعال‌اند یا قابل فعال‌سازی‌اند.
- امکان تغییر Document Root به پوشه `public` وجود دارد.
- حساب ملی‌پیامک و دسترسی API مالک در دسترس است.

هر فرض باید در Phase 0 با تشخیص محیط تأیید یا رد شود.
